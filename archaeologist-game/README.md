# 🦕 Археолог: Энциклопедия динозавров

Детская браузерная игра с образовательным компонентом, где игрок в роли юного археолога ищет останки динозавров, проходит мини-игры и собирает коллекцию динозавров в «Энциклопедии».

## 📋 Описание проекта

**Целевая аудитория:** дети 6–12 лет  
**Платформа:** веб (кроссбраузерно, адаптивно под ПК и планшеты)  
**Возрастной рейтинг:** 0+

## ✨ Особенности игры

### Игровой процесс
Игра состоит из двух последовательных мини-игр:

1. **🏃 Путь к раскопкам** (платформер/уклонение)
   - Проведите персонажа от нижней точки экрана к верхней по лестницам
   - Уклоняйтесь от катящихся сверху булыжников
   - Управление: стрелки/WASD или тапы по сторонам экрана (для планшетов)
   - 3 жизни, сложность нарастает с каждым уровнем

2. **⛏️ Раскопки** (головоломка «три в ряд»)
   - Поле 8×8 клеток с элементами: камень 🪨, кости 🦴, кисточки 🖌️, окаменелости 🐚, самоцветы 💎
   - Классическая механика «три в ряд»
   - Начисление очков: 3 в ряд — 10, 4 в ряд — 25, 5 в ряд — 35
   - Цель уровня: набрать от 500 до 1000+ очков (зависит от уровня)
   - Ограничение по ходам

### 🦖 Коллекция динозавров

После успешного прохождения головоломки игрок получает случайного динозавра из 25 уникальных видов:

- **1 звезда** (первая находка) — краткая справка
- **2 звезды** (10 находок) — развёрнутая статья
- **3 звезды** (25 находок) — развёрнутая статья + интересный факт

**Все 25 динозавров включают:**
- Тираннозавр, Трицератопс, Велоцираптор, Бронтозавр, Стегозавр
- Анкилозавр, Птеродактиль, Спинозавр, Диплодок, Аллозавр
- Игуанодон, Паразауролоф, Карнотавр, Галлимим, Пахицефалозавр
- Дейноних, Компсогнат, Майазавр, Овираптор, Торозавр
- Эораптор, Плезозавр, Ихтиозавр, Мосазавр, Археоптерикс

## 🎮 Как играть

### Регистрация и вход
1. При первом запуске можно:
   - Зарегистрироваться с email и паролем
   - Войти в существующий аккаунт
   - Играть в демо-режиме (без регистрации)

### Прохождение уровней
1. Нажмите **«Играть»** в главном меню
2. Выберите доступный уровень (1 изначально открыт)
3. Пройдите **«Путь к раскопкам»**:
   - Используйте стрелки или WASD для движения
   - Избегайте булыжников 🪨
   - Достигните верха экрана
4. Пройдите **«Раскопки»**:
   - Кликайте на соседние элементы, чтобы поменять их местами
   - Собирайте 3+ одинаковых элемента в ряд
   - Наберите нужное количество очков до окончания ходов
5. Получите случайного динозавра в коллекцию!

### Энциклопедия
- Откройте **«Энциклопедия»** в главном меню
- Просматривайте найденных динозавров
- Кликайте на карточку, чтобы узнать подробности
- Собирайте звёзды, находя динозавров多次

## 🛠️ Технические требования

### Минимальные требования
- Браузер: Chrome 60+, Firefox 55+, Safari 11+, Edge 79+
- Разрешение экрана: от 1024×768
- Поддержка JavaScript ES6+
- localStorage для сохранения данных

### Рекомендуемые требования
- Современный браузер с поддержкой Canvas API
- Сенсорный экран для мобильного управления
- Стабильное интернет-соединение (для первой загрузки)

## 💾 Сохранение прогресса

Прогресс автоматически сохраняется в localStorage браузера:
- ✅ Пройденные уровни
- ✅ Коллекция динозавров (какие виды найдены, сколько раз)
- ✅ Очки и рекорды
- ✅ Разблокированные звёзды в энциклопедии
- ✅ Настройки (звук, музыка, подсказки)

**Важно:** При очистке кэша браузера прогресс может быть потерян. Для демо-режима прогресс сохраняется только в текущей сессии.

## 🐛 Известные ограничения

1. **Демо-режим:** прогресс может сбрасываться при закрытии браузера
2. **Графика:** используются emoji вместо спрайтов (для уменьшения размера)
3. **Звук:** звуковые эффекты не реализованы в базовой версии
4. **Мультиплеер:** не поддерживается
5. **Серверная часть:** используется localStorage вместо базы данных
