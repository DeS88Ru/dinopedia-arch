# 🦴 Археолог: Энциклопедия Динозавров

[![GitHub](https://img.shields.io/badge/GitHub-Repository-blue)](https://github.com)
[![HTML5](https://img.shields.io/badge/HTML5-Game-orange)](https://html5.org)
[![License](https://img.shields.io/badge/License-MIT-green)](LICENSE)

**Интерактивная образовательная игра для детей от 6 лет и их родителей!**

Помоги юному археологу найти останки древних гигантов и собери полную коллекцию динозавров в своей энциклопедии!

## 🎮 Особенности игры

### 🔍 Основные возможности
- **Две увлекательные мини-игры**:
  - 🧗 **Платформер "Подъём к раскопкам"** — преодолей препятствия и доберись до вершины горы
  - 💎 **"Три в ряд"** — собирай кости и инструменты в ряды для получения очков
- **Энциклопедия динозавров** — 10 видов динозавров с подробной информацией
- **Система прогресса** — открывай новые факты о динозаврах
- **Система достижений** — зарабатывай звёзды за находки
- **Сохранение прогресса** — твой аккаунт сохраняется в браузере

## 🚀 Как начать играть

### Вариант 1: Локальный запуск
1. Скачай файл `index.html`
2. Открой его в любом современном браузере (Chrome, Firefox, Safari, Edge)
3. Игра готова!

### Вариант 2: GitHub Pages
1. Создай репозиторий на GitHub
2. Загрузи файл `index.html`
3. Включи GitHub Pages в настройках репозитория
4. Игра доступна по ссылке `https://yourusername.github.io/repo-name/`

### Вариант 3: Хостинг (Netlify, Vercel)
1. Зарегистрируйся на [Netlify](https://netlify.com) или [Vercel](https://vercel.com)
2. Перетащи папку с файлом `index.html` в панель управления
3. Сайт опубликован!

## 🎯 Как играть

### Платформер "Подъём к раскопкам"
```
🎮 Управление:
  ← → или A/D — движение влево/вправо
  ↑ или W — подъём по лестнице
  ↓ или S — спуск по лестнице
  
📱 На мобильном: свайпы по экрану
```

**Цель**: Доберись до вершины горы, избегая падающих булыжников!

**Особенности**:
- 3 уровня сложности (Пустыня, Вулкан, Горы)
- Булыжники становятся быстрее с каждым уровнем
- 3 жизни — используй их мудро!
- Лестницы для подъёма между платформами

### "Три в ряд"
```
🎮 Управление:
  Клик/тап по элементу — выбрать
  Клик по соседнему — поменять местами
  
💡 Совет: собирай 4+ элемента в ряд для бонусных очков!
```

**Цель**: Набери нужное количество очков за ограниченное число ходов!

**Особенности**:
- Разные уровни сложности с различными целевыми очками
- Бонусы за длинные комбинации:
  - 3 в ряд: 10 очков
  - 4 в ряд: 25 очков
  - 5+ в ряд: 35 очков
- Цепные реакции при каскадных совпадениях

### Система прогресса
- **1 находка** — открывается базовая информация о динозавре ⭐
- **10 находок** — открывается подробная статья ⭐⭐
- **25 находок** — открывается интересный факт ⭐⭐⭐

## 👤 Регистрация и вход

Игра использует локальное хранилище браузера для сохранения данных:

1. Нажми "Профиль" в главном меню
2. Введи email и пароль
3. Нажми "Зарегистрироваться" или "Войти"

**Важно**: Данные хранятся только в твоём браузере!

## 🛠️ Технические детали

### Требования
- Современный браузер с поддержкой HTML5, CSS3, ES6+
- JavaScript должен быть включён
- LocalStorage должен быть доступен

### Структура проекта
```
dino-archaeologist/
├── index.html      # Основной файл игры (HTML + CSS + JS)
├── README.md       # Документация
└── .gitignore      # Файлы для исключения из git
```

### Используемые технологии
- **HTML5 Canvas** — для рендеринга платформера
- **CSS Grid & Flexbox** — для адаптивного интерфейса
- **Vanilla JavaScript** — без внешних зависимостей
- **LocalStorage API** — для сохранения прогресса
