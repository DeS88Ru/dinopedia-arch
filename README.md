# 🦕 Археолог: Энциклопедия динозавров

Браузерная игра на **Java** (компилируется в JavaScript через **TeaVM**), предназначенная для публикации на платформе **Яндекс Игры**.

## 🎮 Описание

Игрок в роли юного археолога проходит мини-игры, находит останки динозавров и собирает коллекцию из 25 уникальных видов в энциклопедии.

### Игровой процесс

1. **Авторизация** — регистрация/вход по email и паролю, либо демо-режим
2. **Встреча с персонажем** — профессор Камневедов рассказывает о профессии археолога
3. **«Путь к раскопкам»** — платформер: поднимитесь по лестницам наверх, уклоняясь от катящихся камней
4. **«Раскопки»** — головоломка «Три в ряд» на полях 9×9, 12×12, 16×16. Собирайте кости динозавров, камни, кирпичи и кусты
5. **Находка** — после победы игрок получает случайного динозавра из 25 видов

### Энциклопедия (25 видов динозавров)

| Находок | Звёзды | Контент |
|---------|--------|---------|
| 1 | ⭐ | Краткая справка |
| 10 | ⭐⭐ | Развёрнутая статья |
| 25 | ⭐⭐⭐ | Статья + интересный факт |

## 🛠 Технологии

- **Java 17** — основной язык разработки
- **TeaVM 0.15.0** — компилятор Java → JavaScript для браузера
- **Gradle 8.10** — система сборки
- **HTML5 Canvas API** — рендеринг мини-игр (через TeaVM JSO)
- **DOM API** — интерфейс экранов (через TeaVM JSO)
- **localStorage** — сохранение прогресса

## 🚀 Сборка

### Требования

- JDK 17+
- Gradle 8+ (или использовать `gradle wrapper`)

### Команды

```bash
# Компиляция Java → JavaScript
gradle generateJavaScript

# Сборка дистрибутива (index.html + game.js + css + assets → build/dist/)
gradle buildWebApp
```

Готовая игра находится в `build/dist/` (или в `dist/` в репозитории).

## 📱 Адаптивность

- Корректное отображение на экранах от 1024×768
- Сенсорное управление для планшетов и мобильных устройств
- Клавиатурное управление (WASD / стрелки) для десктопа

## 🎯 Публикация на Яндекс Игры

1. Соберите проект: `gradle buildWebApp`
2. Возьмите содержимое папки `build/dist/` (или `dist/`)
3. Запакуйте в ZIP-архив
4. Загрузите на Яндекс Игры
