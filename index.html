Как выложить игру на GitHub и хостинг

🚀 Часть 1: Подготовка проекта

  1. Создай папку dino-archaeologist
  2. Сохрани этот HTML как index.html в корне папки
  3. Создай README.md с описанием проекта
  4. Создай .gitignore: 
    .DS_Store
node_modules/
.env
*.log

📦 Часть 2: Репозиторий GitHub

  1. Зайди на github.com
  2. Нажми "New repository"
  3. Имя: dino-archaeologist, выбери Public
  4. Поставь галочку "Add a README file"

💻 Часть 3: Загрузка кода

Вариант A — Git CLI:

cd dino-archaeologist
git init
git add .
git commit -m "Initial commit"
git remote add origin https://github.com/НИК/dino-archaeologist.git
git branch -M main
git push -u origin main

Вариант B — GitHub Desktop:

  1. Скачай GitHub Desktop
  2. File → Add Local Repository → выбери папку
  3. Publish repository

Часть 4: GitHub Pages (бесплатно)

  1. В репозитории → Settings → Pages
  2. Source: Deploy from a branch
  3. Branch: main / /root
  4. Нажми Save, подожди 1-3 минуты
  5. Сайт: https://НИК.github.io/dino-archaeologist/

🏠 Часть 5: Хостинг (прод)

Netlify (рекомендуется):

  1. netlify.com → Add new site → Import Git
  2. Выбери GitHub репозиторий
  3. Build command: пусто, Publish dir: /

Vercel:

  1. vercel.com → Import Git Repository
  2. Framework: Other → Deploy

Классический хостинг (Beget, Timeweb):

  1. Загрузи index.html в public_html через FTP/FileZilla
